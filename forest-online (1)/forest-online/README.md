# Выжить в лесу — сервер и приложение

Один репозиторий делает две вещи:
1. **Сервер на Render** — раздаёт игру по ссылке и соединяет игроков (комнаты, публичные и приватные, 2–10 человек).
2. **APK для Android** — приложение, которое подключается к тому же серверу.

## 1. Сервер на Render
1. Загрузите всё содержимое этой папки в репозиторий на GitHub (вместе с `.github`).
2. На render.com: New + → Web Service → выберите репозиторий.
   Язык: Node. Build Command: оставьте пустым (или `echo ok`). Start Command: `node server.js`. Тариф: Free.
   (Либо New + → Blueprint — Render сам прочитает `render.yaml`.)
3. Дождитесь «Live» и откройте адрес вида `https://forest-survival-xxxx.onrender.com` — это игра. Ссылку можно отправлять друзьям: сетевая игра работает прямо в браузере телефона.
Бесплатный тариф засыпает после ~15 минут без посетителей: первый заход после сна открывается 30–60 секунд.

## 2. APK
1. Откройте `android/app/src/main/assets/index.html`, найдите строку
   `window.FOREST_SERVER = "wss://REPLACE-ME.onrender.com/ws";`
   и замените `REPLACE-ME.onrender.com` на адрес вашего сервиса Render (без https://). Сохраните в GitHub (значок карандаша → Commit).
2. Вкладка Actions → Build APK → после зелёной галочки скачайте `app-debug.apk` из Artifacts.
3. Установите на телефон (разрешите установку из неизвестных источников).
Одиночная игра в приложении работает и без интернета; сетевая — только когда сервер доступен.

## Файлы
- `server.js` — сервер (без зависимостей, Node 18+)
- `public/index.html` — игра для сайта
- `android/` — проект приложения (внутри `assets/index.html` — та же игра с адресом сервера)
